# 0001 — Build from scratch

**Status:** Accepted (2026-10-09)

## Context
boring.notch (GPL-3.0, ~11k stars) already covers most planned features. Alternatives were
contributing to it or forking it.

## Decision
Build a new app from scratch. We may study and, with attribution, reuse GPL-compatible code
from boring.notch, Atoll, MewNotch, and MIT code from DynamicNotchKit / NotchDrop.

## Consequences
- Full control over architecture and direction.
- Must justify existence via the lightweight/measured differentiator (ADR-0006).
