# 0010 — Module Menu (navigation)

**Status:** Accepted (2026-10-09)

## Decision
The expanded notch opens to the **most relevant module** (Now Playing while music plays; Shelf
while a file is being dragged). From there the user reaches the **Menu**:
- a small **Favorites grid** of module icons at the top (favorited / most-used), and
- a **scrolling single-column list** of all modules below it.

Users reorder, favorite, and hide modules in the Companion app (ADR-0017).
